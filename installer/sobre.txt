O que o programa faz
  • Mostra os discos ligados ao computador e o sistema instalado em cada partição
    (Windows, Linux, macOS, dados).
  • Abre partições Mac (APFS, HFS+) e Linux (ext2/3/4, também dentro de LVM) e imagens
    de disco (.img, .raw, .dmg) para navegar e copiar arquivos, sem instalar drivers.
  • Monta um volume como uma letra de unidade do Windows (somente leitura), para abrir os
    arquivos directamente em qualquer programa. Esta função usa o driver Dokan 2.
  • Tudo é somente leitura: nada é gravado no disco de origem.

O que este instalador faz
  • Copia o programa (interface gráfica e linha de comando) para a pasta escolhida,
    para o utilizador actual ou para todos os utilizadores do computador.
  • Verifica as dependências: se o driver Dokan 2 não estiver instalado, oferece
    descarregá-lo da página oficial (https://github.com/dokan-dev/dokany, ~9 MB) e
    instalá-lo automaticamente. Nada mais é necessário.
  • Cria atalhos no menu Iniciar (e, se quiser, no ambiente de trabalho) e um desinstalador.
