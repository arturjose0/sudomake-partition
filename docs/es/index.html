SUDOMAKE PartitionLeer, copiar y montar discos Mac y Linux en Windows

Windows no abre discos de Mac (APFS, HFS+) ni de Linux (ext4, LVM). SUDOMAKE Partition sí: muestra las particiones en mosaicos, indica qué sistema hay en cada una y le permite copiar los archivos o montar el disco como una letra de unidad. Gratuito, de código abierto y de solo lectura: no se modifica nada en el disco original.

Qué hace

Para el disco interno sacado de un MacBook, iMac o PC con Ubuntu, Debian, Kali o Fedora, para discos externos y memorias USB formateados en Mac o Linux, y para imágenes de disco.

🍎

Discos Mac

APFS (macOS 10.13 hasta el más reciente, todos los volúmenes, archivos comprimidos) y HFS+/HFSX (Mac OS Plus, Time Machine).

🐧

Discos Linux

ext4, ext3 y ext2, también dentro de volúmenes LVM. Ubuntu, Debian, Kali, Mint, Fedora, RHEL…

💽

Imágenes de disco

DMG (zlib, bzip2, ADC, LZFSE, LZMA), .img, .raw y .dd, con tablas GPT, MBR y Apple Partition Map.

🔎

Detecta el sistema

Cada partición muestra lo que contiene: "Ubuntu 22.04", "Kali Linux", "macOS 12.5", "Windows", "EFI", "swap", "Time Machine"…

🔤

Montar como unidad

El volumen se convierte en una letra (Z:), de solo lectura, visible en el Explorador y en cualquier programa. Varios discos a la vez.

📦

Copiar todo con seguridad

Copie carpetas o el disco completo con progreso, reanudación y registro de errores. Antes de copiar un disco entero comprueba el espacio libre en el destino.

🔒

Solo lectura

Nunca escribe, repara ni altera el disco de origen. No necesita contraseña para discos normales (solo quedan fuera los cifrados).

🌍

4 idiomas y temas

Portugués (Angola), inglés, francés, español. Tema claro, oscuro o del sistema. Los discos conectados o retirados aparecen solos.

Cómo usar

Instale

Descargue el instalador y siga el asistente. Si falta el controlador Dokan (solo para montar unidades), el instalador se encarga.

Conecte el disco y abra

Conecte el disco por USB o adaptador y abra el programa. Acepte la solicitud de Administrador: Windows lo exige para leer discos físicos.

Haga clic en la partición

Los archivos personales están en /Users/nombre (Mac, volumen "Macintosh HD - Data") o /home/nombre (Linux).

Abra, copie o monte

Abrir en el programa para navegar y copiar; Montar como unidad para usar el disco en cualquier programa; Copiar disco completo para llevarlo todo a otro disco.

Preguntas frecuentes

Las dudas más comunes de quien necesita leer un disco Mac o Linux en un PC con Windows.

Windows dice que el disco debe formatearse. ¿Perderé los datos?

No formatee. Windows no reconoce APFS, HFS+ ni ext4 y por eso sugiere formatear. Cierre el aviso, abra SUDOMAKE Partition y el disco aparece con todas sus particiones y archivos.

¿Cómo leer un disco de MacBook o iMac en Windows?

Conecte el disco (adaptador USB/SATA o NVMe, o el disco externo), abra el programa, haga clic en el volumen "Macintosh HD - Data" y copie la carpeta /Users/<nombre>. También puede montar el volumen como letra de unidad (Z:) y abrir los archivos en cualquier programa.

¿Cómo abrir una partición ext4 de Ubuntu, Debian o Kali en Windows?

Abra el programa, haga clic en la partición marcada con el nombre del sistema ("Ubuntu 22.04", "Kali GNU/Linux"…) y copie /home/<nombre>, o móntela como unidad. Las particiones dentro de LVM aparecen como volúmenes separados.

¿Es seguro? ¿Cambia algo en el disco?

No. El programa es de solo lectura: nunca escribe, repara ni monta en modo escritura. El disco queda exactamente como estaba y puede volver al Mac o al equipo Linux.

¿Necesito la contraseña del Mac o de Linux?

No para discos normales: la contraseña de inicio de sesión solo protege la sesión; los archivos están guardados sin cifrar. Solo los discos cifrados a propósito (FileVault, LUKS, eCryptfs) no pueden abrirse.

¿Cuánto cuesta? ¿Es una alternativa a Paragon, MacDrive o Linux Reader?

Es gratuito y de código abierto (licencia MIT), sin límites ni versión de pago. Lee Mac y Linux en el mismo programa, indica qué sistema hay en cada partición y no instala controladores para leer o copiar. Si le ayuda, se agradece una donación de cualquier importe.

    Requisitos y notas

    • Windows 10 u 11 de 64 bits. No hace falta instalar nada más.
    • El instalador (recomendado) instala para su usuario o para todos, crea accesos directos y desinstalador, y descarga el controlador Dokan 2 si falta.
    • La versión portátil (zip) no necesita instalación: descomprima y ejecute SudomakePartition.exe.
    • Leer un disco físico exige permisos de Administrador; el programa los pide al abrir.
    • No abre discos cifrados (FileVault, LUKS, eCryptfs) ni Macs con chip T2 o Apple Silicon.
